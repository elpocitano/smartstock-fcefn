# SmartStock FCEFN ⚒️

**Gestión inteligente de activos para el Departamento de Geología** *Proyecto Integrador: Diseño Web | Base de Datos | Backend | Ciberseguridad*

---

## 📌 Visión del Proyecto
**SmartStock** es una solución digital diseñada para modernizar la gestión de inventario y el control de préstamos de equipamiento técnico en la **Facultad de Ciencias Exactas, Físicas y Naturales (UNSJ)**. 

Este proyecto nace para reemplazar registros manuales por una arquitectura robusta, segura y escalable, garantizando la **soberanía tecnológica** mediante el uso de herramientas de código abierto.

## 🚀 Objetivos Académicos
Este sistema ha sido diseñado aplicando los estándares exigidos en las cátedras de:
* **Diseño Web:** Interfaz *Mobile-First* utilizando HTML5, CSS3 y Bootstrap 5.
* **Base de Datos:** Implementación de un modelo relacional normalizado en **PostgreSQL**.
* **Backend:** Lógica de negocio integrada con **Supabase** y arquitectura de *Vertical Slicing*.
* **Ciberseguridad:** Implementación de políticas de acceso a nivel de fila (RLS), autenticación vía JWT y protección de datos sensibles.

## 🛠️ Stack Tecnológico
* **Frontend:** JavaScript Vanilla (ES6+), Bootstrap 5.3.
* **Backend as a Service:** Supabase.
* **Base de Datos:** PostgreSQL.
* **Documentación:** Markdown.
* **Licencia:** MIT.
